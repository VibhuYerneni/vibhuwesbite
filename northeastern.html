Northeastern Projects

The Challenge & Process

Across my Northeastern coursework I tackled projects that combined hardware, embedded systems, and software—from an interactive museum exhibit to a hexapod robot and a secure password generator. Each project started with clear constraints and user or system requirements, then moved from prototyping to implementation and testing.

For Thunderstruck (Cornerstone 2), the challenge was building a puzzle experience for the Boston Children’s Museum: five pieces forming Zeus’s lightning bolt, with photoresistor-based detection on a wooden grid and an Arduino–Python stack for hints, timer, and instructions. For the spider robot, the focus was embedded control—servo-driven legs, walking algorithms, and mechanical design. For the password generator, the goal was cryptographic security, configurable parameters, and a clear interface with strength evaluation.

The Solution & Impact

Thunderstruck went from a cardboard-and-magnets prototype to a finished exhibit; we tested it at the museum and players replayed to beat their best times. The hexapod used a central microcontroller for coordinated leg movement, power management, and real-time locomotion. The password tool used secure random generation and strength metrics so users could create and validate strong passwords. Thunderstruck has a full project site documenting the process; the spider and password projects reinforced embedded and security fundamentals that I’ve applied in later work.
